# Components

- **`OCCTSwiftPDF`** (library): the `PDF` namespace. It re-exports SwiftDXF, whose `DXF.Drawing`
  is what a PDF is read into.
- **`pdfprobe`** (executable): reports what PDF drawings are made of.
